# Screenshots

These images are referenced from the top-level [`README.md`](../../README.md)
"Screenshots" section. To refresh them, drop replacement PNGs in this folder
using the **exact filenames** below — the README links to them by name.

| Filename | What it shows | Suggested capture |
|---|---|---|
| `game-session.png` | A live DragonRealms session — game stream, Room panel, Backpack/inventory, and the Logons/Talk/Whispers/Thoughts/Combat stream tabs, with the vitals bar. | Connected, standing in a well-described room (e.g. Riverhaven, Town Hall Road). Whole window. |
| `mapper.png` | The Mapper panel — zone picker with its sort control, Edit/Record/New/Save/Labels toolbar, level controls, the map canvas and its legend. | Mapper window with a zone loaded (or the "No zone loaded" empty state). |
| `connect-dialog.png` | The **Connect to DragonRealms** dialog — Profile, Mode, Instance, Account/Password, Character fetch, and the TLS toggle. | File → Connect…, either empty or with a saved profile loaded. If a profile is loaded, replace the profile, account and character names with placeholders. |

## Tips

- **Crop to the window**, not the whole desktop — no taskbar or wallpaper.
- **Don't capture credentials or names.** No account name, password or
  character name in any image: leave the fields empty, or replace them with
  placeholders such as `Character-Account`. Keep other players' names and
  speech out of frame too.
- PNG, captured at 100% display scaling. ~1000–2000 px wide is plenty; GitHub
  scales them down in the rendered README.

The current set was captured on 5.0.0 and matches `wiki/images/`
(`interface-default-layout.png`, `mapper-panel.png`, `connect-dialog.png`).
